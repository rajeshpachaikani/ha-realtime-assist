# This directory contains OpenWakeWord model files

Place your OpenWakeWord .onnx model files here.

Download models from: https://github.com/dscripka/openWakeWord

Popular models:
- alexa_v0.1.onnx
- hey_jarvis_v0.1.onnx
- hey_mycroft_v0.1.onnx

Set the OWW_MODEL_PATH environment variable to point to your chosen model file.
